# 🎓 Calculadora de CR Profissional

Uma ferramenta web moderna para estudantes calcularem o Coeficiente de Rendimento (CR) de forma simples e rápida. 



## 🚀 Funcionalidades
- **Cálculo Dinâmico:** Adicione quantas disciplinas precisar.
- **Design Responsivo:** Otimizado para dispositivos móveis (Mobile First).
- **Média Ponderada:** Cálculo baseado em nota e carga horária (peso).
- **Feedback Visual:** Resultado com cores indicativas de desempenho.
- **Limpeza Rápida:** Botão para resetar todos os campos.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estrutura semântica.
- **CSS3:** Estilização com Flexbox e Media Queries.
- **JavaScript (ES6+):** Manipulação de DOM e lógica matemática.
- **GitHub Pages:** Hospedagem gratuita.
